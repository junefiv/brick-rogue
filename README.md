# ROGUE BREAKER · Android 플레이테스트 0.4.0

0.4.0에서는 Sprite2D, AnimatedSprite2D, GPU 파티클, 셰이더와 Tween 기반 VFX를 추가했습니다. 기본 패시브 12종·액티브 8종을 전투에서 테스트할 수 있습니다. 관통은 발사 시 지정되는 화살 공이며, 리바운드는 바닥에서 확률적으로 재반사합니다.

메뉴 하단 **VFX STUDIO**에서 기본 20종과 융합 94종의 연출을 재생합니다. 기본 스킬을 선택하고 **이 기본 스킬 테스트**를 누르면 해당 Lv.5 스킬만 장착한 테스트 랩이 열립니다. 융합 94종은 연출 라이브러리이며 모든 신규 융합의 전투 규칙이 연결된 상태는 아닙니다. 상세 상태는 [VFX 구현 현황](docs/VFX_구현현황.md)에 기록했습니다.

기획서의 핵심 루프를 실제 플레이로 확인하는 **Godot 4.7.2 / GDScript 네이티브 게임**입니다. 웹/PWA가 아닙니다. 개발 프로젝트와 빌드 도구 모두 C드라이브의 이 작업 폴더에 있습니다.

## 휴대폰에서 실행

1. 이 프로젝트 폴더 바로 위의 **RogueBreaker-Android.apk**를 Android 휴대폰의 다운로드 폴더로 복사합니다. USB 파일 전송, Quick Share 등 평소 사용하는 파일 전송 방법을 쓰면 됩니다.
2. 휴대폰의 파일 관리 앱에서 APK를 누릅니다.
3. 설치를 요청한 파일 관리 앱에 대해 **이 출처의 앱 설치 허용**이 필요한 경우 허용하고 설치합니다. 제조사에 따라 메뉴 이름이 다릅니다.
4. **ROGUE BREAKER**를 실행합니다. 계정과 인터넷 연결은 필요 없습니다.

Android 7.0(API 24) 이상, ARM64/ARMv7/x86_64 빌드입니다. 스토어 출시용 앱이 아닌 개발용 서명 APK입니다. 기존 다른 서명 버전이 설치돼 있으면 업데이트가 거절될 수 있습니다. 이 경우 저장 데이터를 보존할지 먼저 결정한 뒤 처리하세요.

### 첫 테스트 순서

- **새로운 다이브 시작**: 기본 공 8개로 시작합니다.
- 필드를 누르고 드래그하여 각도를 정한 뒤 손을 놓습니다. 위쪽을 가리키거나 아래로 당기는 방식 둘 다 지원합니다.
- 첫 번째로 돌아온 공의 X좌표가 다음 발사 위치가 됩니다.
- 벽돌 파괴로 XP를 모아 3개 카드 중 1개를 선택합니다.
- 벽돌 파괴로 POINT가 함께 쌓입니다. 조준 단계의 `공 +1` 버튼은 클릭 한 번에 공을 정확히 1개만 구매하며, 공이 늘 때마다 다음 가격이 50 POINT씩 올라갑니다. 수량 입력과 일괄 구매는 없습니다.
- 구매 영역은 보유 공·보유 POINT·다음 가격을 함께 보여주며, 스킬 칸을 누르면 효과와 쿨다운을 설명합니다.
- 전체 안전 화면을 채우고, 아래로 당기는 단일 조준 방식으로 화면 끝에서 방향이 튀는 현상을 막았습니다.
- 하단 액티브는 조준 단계에서만 사용합니다. 레이저/폭격은 버튼을 누른 뒤 다시 조준합니다.
- **테스트 랩**: 공 300개, 벽돌 63개, 최대 강화 스킬로 시작합니다. 하단 **FUSION READY**를 눌러 융합을 즉시 확인할 수 있습니다.
- 테스트 랩에서는 위험선을 넘으면 필드를 재생성하고 현재 빌드를 유지합니다. 일반 게임의 패배 규칙과 구분되는 반복 실험용 모드입니다.
- 설정에서 LOW(64)/BAL(96)/HIGH(128) 실제 공 상한과 효과음을 바꿀 수 있습니다. 논리 공 수는 유지됩니다.

## 이번 빌드에 없는 항목

원본 기획 전체가 완성된 버전은 아닙니다. 새 융합 94종의 전투 규칙 전체 연결, 보스별 고유 패턴, 코어 선택·메타 성장, 계정·클라우드 저장·랭킹, 광고·결제, BGM·전문 사운드, Daily 등은 미구현입니다. 최신 VFX 구현 범위는 `docs/VFX_구현현황.md`에 있습니다.

보스는 현재 큰 HP 벽돌입니다. 네 가지 보스의 방어 파트/중력/증식 패턴을 구현했다고 보지 마세요. 카드 추첨도 현재 균등 추첨이며 기획서의 신규/강화 45:55와 희귀도 가중치는 아직 적용하지 않았습니다.

## PC 개발

- Godot에서 `project.godot`를 열고 F6 또는 F5로 실행합니다.
- 이 PC에서는 `Play.ps1`을 실행하거나 `START-GAME.cmd`를 더블클릭할 수 있습니다.
- `Build-Android.ps1`은 현재 APK를 같은 경로에 다시 만듭니다.
- `Test.ps1`은 별도 저장 경로에서 규칙 테스트를 실행합니다. `-Visual`은 화면/입력 테스트, `-Stress`는 15분 분량의 시뮬레이션 부하 테스트입니다.
- Godot 실행 파일과 템플릿: 작업 루트의 `work/tools/godot`.
- Java 17 및 Android SDK는 이 PC에 있던 설치를 사용합니다. 내보내기 설정은 Godot 휴대형 편집기 설정에 있습니다.
- Android APK는 `export_presets.cfg`의 Android 프리셋으로 내보냅니다. 개발용 키를 잃으면 기존 앱 위에 덮어쓰기가 불가능할 수 있으므로 보관해야 합니다.

## 코드 구조

```text
project.godot          프로젝트 / 모바일 설정
data/balance.json     스킬, 융합, HP·XP 공식 계수, 성능 상한
game/run_model.gd     라운드, 성장, 전투 이벤트, 저장
game/ball_simulation.gd  가중 공 / 연속 충돌 / 그리드 검색
ui/game.gd            화면, 입력, 상태 전환, 효과·사운드
tests/               규칙·UI·부하 테스트
docs/                기획 분석, 검증 기록
```

외부 이미지 없이 기하학 도형으로 화면을 그립니다. 한글 글꼴은 Noto Sans KR이며 `assets/OFL.txt`를 함께 포함합니다. Godot 및 포함 라이브러리 고지는 `docs/Godot-LICENSE.txt`, `docs/Godot-COPYRIGHT.txt`에 있습니다.

## 실기기 테스트 기록

반드시 휴대폰에서 확인할 항목:

1. 기종 / Android 버전 / 선택한 성능 모드
2. 기본 모드 5~10라운드 조준감, 터치 정확도, 첫 복귀 위치
3. 테스트 랩에서 공 300개와 융합 조합; FPS, 프레임 멈춤, 발열
4. 앱 전환/화면 잠금/강제 종료 후 재개
5. 노치, 하단 내비게이션, 긴 화면비에서 UI 잘림
6. 처음 레벨업과 첫 융합까지 걸리는 시간

PC 자동 검사와 APK 서명 검증은 휴대폰의 발열·터치감·실제 FPS 검증을 대신하지 않습니다.

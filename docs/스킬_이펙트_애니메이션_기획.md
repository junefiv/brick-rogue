# ROGUE BREAKER 스킬 이펙트·애니메이션 기획

## 1. 관통 규칙 수정

- 관통 확률은 벽돌 충돌마다 판정하지 않고 각 공이 발사되는 순간 한 번 판정한다.
- 관통 공으로 선택된 공은 바닥으로 돌아올 때까지 모든 벽돌을 통과한다.
- 좌우·상단 벽에는 일반 공처럼 반사한다.
- 관통 공도 충돌 피해와 패시브 발동 판정을 정상 적용한다.
- Lv.1~5 관통 공 출현 확률은 `9/18/27/36/45%`다.
- 관통 공은 진행 방향으로 회전하는 화살 스프라이트으로 일반 공과 즉시 구분한다.
- 관통 관련 융합의 효과는 모두 이 관통 공에 적용한다.

## 2. 공통 연출 규칙

### 2.1 연출 단계

1. **예고:** 발동 위치와 범위를 0.15~0.4초 먼저 보여준다.
2. **발동:** 실제 판정과 같은 위치·순서로 핵심 효과를 재생한다.
3. **결과:** 동결, 부식, 현상금, 공명처럼 지속되는 상태를 벽돌 표면에 남긴다.

### 2.2 색상 언어

| 계열 | 색상 | 형태 |
|---|---|---|
| 파워 | 주황·백색 | 충돌점 섬광과 타격 파편 |
| 관통 | 청백색 | 창, 절단선, 직선 잔상 |
| 폭발 | 분홍·주황 | 격자 충격파, 화염 파편 |
| 번개 | 보라·백색 | 지그재그 전류, 수직 낙뢰 |
| 서리 | 하늘색 | 다면 얼음 조각과 고드름 |
| 치명타 | 금색 | 십자 섬광, 절단 흔적 |
| 월 차지 | 주황·적색 | 붉어지는 공과 최대 충전 불꽃 |
| 부식 | 녹색 | 액체, 기포, 표면 균열 |
| 현상금 | 금색·갈색 | 보물상자 개방, 금화 분출 |
| 분열 | 청록색 | 작아진 자식 공 |
| 공명 | 청록·보라 | 동심원, 진동선 |
| 리바운드 | 백색·민트 | 바닥 반사, REBOUND 액션 텍스트 |

### 2.3 가독성 원칙

- 일반 벽돌에는 문자 배지를 붙이지 않는다.
- 동결은 벽돌 전체의 얼음 표면과 결정으로 표시한다.
- 부식은 녹색 균열과 액체 흐름으로 표시한다.
- 현상금은 벽돌 바깥 모서리 조준선으로 표시한다.
- 공명 누적은 벽돌 안쪽의 얇은 동심원 개수와 밝기로 표시한다.
- 동시에 같은 효과가 여러 번 발생하면 하나의 굵은 효과로 합산한다.
- 이펙트가 체력 숫자와 체력바를 0.2초 이상 가리지 않게 한다.
- 큰 화면 흔들림은 액티브와 대형 융합에만 사용한다.
